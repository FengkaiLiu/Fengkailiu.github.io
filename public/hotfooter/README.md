# Hot Footer media

Drop the in-game screenshots here, named:

- `shot-1.jpg`
- `shot-2.jpg`
- `shot-3.jpg`

JPG (or PNG renamed to the same pattern with `.png`), any size; around 1600 px wide is plenty.
They appear in the Hot Footer liner notes in this order.

`game/` holds the playable Lava Rising build, generated by `node scripts/export-hotfooter.mjs`
from the GameDevGroup4/Unity-Project repo. Do not edit it by hand.
